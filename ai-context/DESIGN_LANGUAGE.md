# DESIGN LANGUAGE

Enso 8 should feel:
- cinematic
- premium
- minimal
- technical
- restrained
- immersive

Primary inspirations:
- Apple
- Linear
- Raycast
- high-end production studios
- cinematic editorial transitions

Core visual identity:
- black negative space
- sparse typography
- cyan accent details
- fullscreen video transitions
- restrained motion
- smooth sequencing

Motion Philosophy:
Motion should feel:
- deliberate
- smooth
- editorial
- film-like
- premium
- subtle

Avoid:
- exaggerated tilt
- flashy gamer aesthetics
- overuse of glow
- generic SaaS card feel
- noisy gradients
- abrupt animation
- artificial depth
- tiny mobile UI
- excessive blur

Interaction Style:
Cursor interactions should feel:
- magnetic
- subtle
- reactive
- cinematic
- physically believable

Never:
- shake UI aggressively
- over-rotate elements
- distort perspective unnaturally

Typography:
- readable on mobile
- restrained
- spacious
- cinematic
- not oversized
- not compressed

Transitions:
Transitions should feel continuous,
never like disconnected page swaps.
